# Folder Assets BIOS Playdita (Lemuroid)

Letakkan file BIOS Game Boy Advance (GBA) di folder ini dengan nama:
gba_bios.bin

Informasi file BIOS resmi GBA:
- Nama file: gba_bios.bin
- Ukuran: 16.384 bytes (16 KB)
- MD5: a860e8c0b6d573d191e4ec7db1b1e4f6
- CRC32: 81977335

Catatan:
1. Anda juga dapat meletakkan file gba_bios.bin langsung di folder assets (lemuroid-app/src/main/assets/gba_bios.bin).
2. Ketika aplikasi dijalankan atau game GBA dimainkan, file BIOS ini akan otomatis dimuat ke direktori sistem emulator.
3. Fitur "Boot BIOS" pada pengaturan umum akan menjalankan animasi boot intro Nintendo Game Boy Advance setiap kali game dimulai.
